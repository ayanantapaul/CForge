# CForge

> A curated collection of classic and modern algorithms implemented in C.

![Language](https://img.shields.io/badge/Language-C-00599C?logo=c&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-blue)

## Why CForge?

Most algorithm collections target Python or Java. CForge fills the gap with
clean, well-commented C implementations that focus on **correctness**,
**readability**, and **portability** — no external dependencies.
